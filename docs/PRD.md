# 需求文档：采购明细发票匹配与金蝶下推改造

**状态**：草稿  
**作者**：产品（原型对齐）  
**更新日期**：2026-08-20  
**版本**：0.1  
**干系人**：财务结算、采购、金蝶集成、前端/后端

---

## 1. 问题与背景

现状进项发票按整张采购送货单（CDN）做 1:1 匹配，无法覆盖 1:N / N:1 / N:N。匹配成功后才回写金额，应付单与采购单又在「采购送货单推金蝶 / 随单采推金蝶」分散下推，容易把不同发票的明细打进同一张金蝶采购单，应付单口径错乱。

不解决的代价：苏豪靠备注 Y2、非苏豪靠购销方+价税合计的头匹配一旦金额或行拆分，只能人工；金蝶采购/应付重复推送、漏推、错票。

---

## 2. 目标与成功指标

| 目标 | 衡量指标 | 达成标准 |
|------|----------|----------|
| 支持行级匹配 | 发票行可跨 CDN 占用采购行 | 1:N、N:1、N:N 可落库 |
| 整票进金蝶 | 已匹配发票的金蝶采购单 = 一张票的全部占用行 | 不允许混票下推 |
| 应付单自动且可拦截 | 定时任务按金蝶采购单整单下推应付 | 无发票或部分匹配跳过；同一单多个发票号 → 推送异常 |
| 职责收口 | 匹配/采购下推只在新模块 | 旧两页去掉对应按钮 |

---

## 3. 本次不做

- 本次不改销售直发单推金蝶。
- 随单采的**销售单**推金蝶逻辑不变。
- 本迭代不做单独的「打包金蝶采购单 / 解绑打包」；生成单号与下推在「采购单下推金蝶」一次完成。
- 不在本迭代做金蝶采购单红冲/反审自动解绑。
- 不替换进项发票导入、数电票解析。
- 第一期不自动拆分数量（一行采购拆给多张发票行需人工拆行后再配，见开放问题）。

## 4. 用户故事

**故事 1**  
作为结算会计，我想在采购送货单**行**上匹配发票行，以便一张票对应多张 CDN、或一张 CDN 对应多张票。

验收：
- [ ] 前提：未匹配采购行；当选择发票且型号+数量对齐；则占用发票行并回写开票金额/税额/价税合计/费用金额。
- [ ] 前提：发票仅部分行被占用；则进项发票表头为「部分匹配」。
- [ ] 前提：全部发票行均有采购行；则表头为「全部匹配」，否则「未匹配」。
- [ ] 前提：采购单未下推，或已下推但应付未成功；当解绑发票或重新匹配；则允许；金蝶采购单号保留。
- [ ] 前提：应付已推送成功；当解绑发票或匹配发票；则拒绝。

**故事 2**  
作为结算会计，勾选要按整票联动，并支持多组一起确认下推金蝶。

验收：
- [ ] 前提：勾选任一已匹配行；当勾选；则自动勾选同一发票占用的全部采购行（可与其他组并存，可跨 CDN）。
- [ ] 前提：行无发票；当勾选；则只勾本行（有金蝶采购单号也不连带）。
- [ ] 前提：仅勾选有发票的行（可多张票）；当采购单下推金蝶；则每张发票各生成一个金蝶采购单号并下推。
- [ ] 前提：仅勾选无发票的行；当采购单下推金蝶；则勾选行打成一个金蝶采购单号并下推。
- [ ] 前提：有发票与无发票混合勾选；当采购单下推金蝶；则有票按票拆成多单下推，无票打成一个单号下推。
- [ ] 前提：所选组已推送成功；当下推；则该单号跳过。

**故事 3**  
作为系统，定时任务按金蝶采购单整单下推应付单。

验收：
- [ ] 前提：采购已下推成功 + 全部明细已匹配 + 发票号唯一；当任务运行；则应付推送成功。
- [ ] 前提：采购已下推成功 + 整单无发票或行明细部分匹配；当任务运行；则跳过不推送，应付保持未推送，不报推送异常。
- [ ] 前提：同一金蝶采购订单存在多个发票号；当任务运行；则应付状态=推送异常，不调用金蝶应付，待人工解绑/重配。

## 5. 方案概述

新建菜单 **财务管理 / 结算管理 / 采购明细发票匹配**，以采购送货单行数据为主数据。进项发票、采购送货单推金蝶、随单采（采购部分）只消费本模块结果。

### 5.1 金蝶采购单号

| 项 | 规则 |
|----|------|
| 编码 | `KDCG` + `YYMMDD` + 4 位当日流水 |
| 示例 | `KDCG2608190001` |
| 范围 | 全组织按自然日递增 |
| 共用 | 同一张发票 / 一次未配行下推 共用一号；一次勾选多张票则拆成多个单号 |
| 作废 | 解绑发票不清空单号；原号不回收，避免与金蝶侧冲突 |

### 5.2 勾选与下推

本迭代不做单独打包/解绑打包。点「采购单下推金蝶」时生成单号并下推。

```
勾选一行
  1. 有发票 → 勾上该发票占用的全部采购行（可跨 CDN）
  2. 无发票 → 只勾本行
  多组可同时勾选，不互斥

确认下推金蝶（按钮：采购单下推金蝶）
  仅勾选有发票 → 按整张发票生成一个金蝶采购单号并下推；支持多张发票，按票拆分下推
  仅勾选无发票 → 按勾选行打包生成一个金蝶采购单号并下推
  有发票和无发票混合勾选 → 有发票的按票拆分多单下推；没有发票的打包生成一个金蝶采购单号并下推
  已推送成功的单号跳过；组内若已有未推送单号则复用
```

### 5.3 发票匹配（行明细级别）

匹配规则：
1. 苏豪：发票备注 Y2 = 采购送货单舜天发货单号；失败则走 3（**本迭代先不做**）。
2. 三菱重工优先 SO 路径（备注找不到单据或行对不上则走 3 — **本迭代先不做**）：
   - 从进项发票备注解析 SO 单号（现网形态：`SO-260323-071-Q`，多个以空格分隔）。
   - SO = 采购订单「供应商订单号」→ 得到采购订单号 → 再找该订单下的采购送货单。
   - 在勾选的未匹配行上按型号+数量先到先占用（一张票多个 SO、或多张票同一 SO，规则相同：先配先占，剩余给后面）。
3. 其他物优家，以及三菱 SO 未命中时：购方=销售公司，销方=供应商，行上按型号+数量占用。本迭代仅落地其他物优家；三菱 SO 未命中走 3 **先不做**。

匹配成功回写采购行：开票不含税、税额、价税合计、费用金额。进项发票行记录占用的采购送货单号+行号。匹配成功不自动生成金蝶采购单号；由「采购单下推金蝶」按票/未配行生成并下推。

解绑 / 重新匹配发票：仅当该行应付单未推送成功。采购单已下推成功不影响改票；应付成功后不可再改。解绑后清空回写金额（金蝶采购单号保留）。
- a. 采购单未下推金蝶：可以解绑、重新匹配。
- b. 采购单已下推金蝶、应付单未下推金蝶：可以解绑、重新匹配。
- c. 应付单已下推金蝶：不可解绑、不可重新匹配。

### 5.4 应付单定时任务

扫描条件：已下推金蝶采购订单（推送成功）+ 应付未成功 + 有金蝶采购单号。按金蝶采购订单整单下推应付单。

- 通过：下推应付单，状态推送成功。
- 整单无发票，或行明细部分匹配：跳过不推送，应付保持「未推送」，**不报推送异常**。
- 一张金蝶采购订单中有多个发票号：状态「推送异常」，人工在新模块解绑/重配发票后再跑任务（应付未成功即可改票；应付已成功走线下/后续红冲需求）。

### 5.5 旧模块调整

**进项发票**
- 去掉整单 CDN 匹配语义。
- 表头匹配状态 = 明细汇总：未匹配 / 部分匹配 / 全部匹配。
- 列表「采购签收单号」改为展示占用到的 CDN（多值）。
- 不在本页做匹配/解绑/下推。

**采购送货单推金蝶**
- 表头增加只读 **采购推送状态**、**应付推送状态**，由明细汇总：未推送 / 部分推送 / 全部推送（全部行为金蝶采购推送成功 / 应付推送成功才算全部）。
- 只读展示匹配结果、回写金额、金蝶采购单号。
- 明细行采购下推展示未推送/推送成功/推送失败（不再使用「未打包」）。
- 删除：采购单批量推金蝶、应付单批量推金蝶；详情删除采购单/应付单推送、关联发票编辑/解绑。

**随单采推金蝶（三单匹配）**
- 采购部分同「采购送货单推金蝶」。
- 详情保留 **销售出库明细**（产品、数量、退货、政策价、发货仓等），销售逻辑不变。
- 保留销售单批量推金蝶、详情销售单推金蝶。

**销售直发单推金蝶**：不变。

## 6. 技术考虑

**依赖**
- 金蝶采购订单、应付单接口 — 负责方：集成 — 风险：中
- 进项发票行表、采购送货单行表增加匹配外键与金蝶单号字段 — 负责方：后端 — 风险：低
- 定时任务（建议 15–30 分钟）— 负责方：后端 — 风险：低

**已知风险**

| 风险 | 可能性 | 影响 | 缓解措施 |
|------|--------|------|----------|
| 未匹配混包后补配成多张发票 | 高 | 应付异常 | 任务拦截+列表红标；操作手册建议先匹配再下推 |
| 发票行型号与采购型号不一致 | 高 | 匹配失败 | 保留手工选票；后续可做别名表 |
| 已推送应付单无法改票 | 中 | 人工金蝶处理 | 应付成功后不可解绑；应付未成功允许重配 |

**开放问题**
1. 采购行数量与发票行数量不等时，是否允许拆行？第一期默认不允许，需先在业务上拆采购行。
2. 应付「推送异常」是否提供「强制按指定发票重推」？建议第一期不做。
3. 「下推」是生成单号即调用金蝶。原型在点「采购单下推金蝶」时占号并置为推送成功；种子数据中未推送单号可在下推时复用。已成功单号跳过。本迭代不做单独解绑打包。

## 7. 页面与字段（第一期）

新模块列表（行）：采购送货单号、供应商订单号、行号、产品编号、产品名称、产品型号、实际采购数量、采购政策价、供应商、销售公司、行匹配、发票号、发票匹配（未匹配 / 部分匹配 / 全部匹配）、采购开票价、使用费用、金蝶采购单号、采购推送状态、应付推送状态。

筛选：采购送货单号、舜天发货单号、供应商、销售公司、发票号、发票匹配（全部匹配 / 部分匹配 / 未匹配）、金蝶采购单号、产品名称、采购单下推、应付单下推。

按钮：匹配发票、解绑发票、采购单下推金蝶、应付单下推金蝶。

匹配弹窗：只列出未匹配、部分匹配的进项发票（全部匹配的不展示）。展示本次勾选采购行（产品名称/型号/数量/**采购政策价**），发票列表含发票备注；选中发票后展示明细行货物名称、型号、数量、**费用金额**、**开票金额**（价税合计，已扣减费用）。

# 采购明细发票匹配 · 可交互原型

财务管理 / 结算管理改造原型：行级发票匹配、按票/未配行下推金蝶采购订单、应付单按单校验。

## 运行

```bash
cd ~/Projects/invoice-line-matching
npm install
npm run dev
```

浏览器打开终端提示的本地地址（一般为 `http://localhost:5173`）。

## 页面

| 菜单 | 说明 |
|------|------|
| 采购明细发票匹配 | 新模块：勾选、匹配、解绑发票、采购/应付下推 |
| 进项发票 | 表头匹配状态随明细变化 |
| 采购送货单推金蝶 | 只读；采购/应付下推按钮已去掉 |
| 随单采推金蝶 | 采购只读；销售推金蝶仍可点 |

## 建议点选路径

1. 勾选列表首行 `CDN202608200051` → 匹配发票。弹窗核对发票备注 `Y260820KT0051`、明细货物名称/型号/数量后，确认 INV-J。
2. 三菱多 SO：同时勾 `CDN202608140001`、`CDN202608140002` → 匹配 INV-G，按型号+数量先到先占用。
3. 三菱同一 SO：勾 `CDN202608130001` → 先配 INV-H（室外机），剩余行再配 INV-I。
4. 三菱备注无 SO：本迭代不走购销方兜底（先不做）。
5. 勾选已匹配发票行（自动带出该票全部占用行）→「采购单下推金蝶」：按票生成 `KDCG+日期+流水` 并下推；多张票拆成多单。
6. 无发票行只勾本行：可多选 P11、P12 后「采购单下推金蝶」，打成一个单号（已有 `KDCG2608160003` 则复用）。可与已匹配发票同时勾选混合下推。
7. 点「应付单下推金蝶」：无发票或部分匹配的金蝶采购单跳过、应付保持未推送；`KDCG2608150001` 因多个发票号保持「推送异常」。应付未成功前可解绑/重配发票。

金蝶采购单号规则：`KDCG` + `YYMMDD` + 4 位当日流水，例如 `KDCG2608190001`。解绑不回收号段。

需求正文：`docs/PRD.md`。

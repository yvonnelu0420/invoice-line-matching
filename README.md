# 采购明细发票匹配 · 可交互原型

财务管理 / 结算管理改造原型：行级发票匹配、整票打包下推金蝶采购订单、应付单按单校验。

## 运行

```bash
cd ~/Projects/invoice-line-matching
npm install
npm run dev
```

浏览器打开终端提示的本地地址（一般为 `http://localhost:5173`）。

## 页面

| 菜单 | 说明 |
|------|------|
| 采购明细发票匹配 | 新模块：勾选、匹配、打包、解绑、模拟应付任务 |
| 进项发票 | 表头匹配状态随明细变化 |
| 采购送货单推金蝶 | 只读；采购/应付下推按钮已去掉 |
| 随单采推金蝶 | 采购只读；销售推金蝶仍可点 |

## 建议点选路径

1. 勾选 `CDN202608190039` 任意一行未匹配明细 → 匹配发票 → 选 INV-A（Y2 命中）→ 确认。勾任意已配行应带出整票三行。
2. 点「打包下推金蝶采购订单」生成 `KDCG+日期+流水`，状态未推送；再「确认下推金蝶」。
3. 勾选 `KDCG202608160003` 两行 →「解绑打包」可重打。
4. 点「模拟应付单定时任务」：`KDCG202608150001` 因两张发票不一致保持「推送异常」。
5. 打开进项发票，看 INV-B 全部匹配（跨两张 CDN）、INV-E 部分匹配。

金蝶采购单号规则：`KDCG` + `YYYYMMDD` + 4 位当日流水，例如 `KDCG202608190001`。解绑不回收号段。

需求正文：`docs/PRD.md`。

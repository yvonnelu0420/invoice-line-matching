# 采购明细发票匹配 · 可交互原型

财务管理 / 结算管理改造原型：行级发票匹配、整票打包下推金蝶采购订单、应付单按单校验。

## 运行

```bash
cd ~/Projects/invoice-line-matching
npm install
npm run dev
```

浏览器打开终端提示的本地地址（一般为 `http://localhost:5173`）。

## 页面

| 菜单 | 说明 |
|------|------|
| 采购明细发票匹配 | 新模块：勾选、匹配、打包、解绑、模拟应付任务 |
| 进项发票 | 表头匹配状态随明细变化 |
| 采购送货单推金蝶 | 只读；采购/应付下推按钮已去掉 |
| 随单采推金蝶 | 采购只读；销售推金蝶仍可点 |

## 建议点选路径

1. 勾选列表首行 `CDN202608200051` → 匹配发票。弹窗核对发票备注 `Y260820KT0051`、明细货物名称/型号/数量后，确认 INV-J。
2. 三菱合并开票：勾 `CDN202608140001` 任一行 → 匹配发票，INV-G 应显示「SO 命中」→ 确认后两张 CDN 都占用（备注两个 SO）。
3. 三菱拆分开票：勾 `CDN202608130001` 任一行 → 先配 INV-H（只中室外机），再勾剩余行配 INV-I（同一 SO）。
4. 三菱备注无 SO：勾 P11 → 配 INV-F，走购销方原路径。
5. 点「打包金蝶采购单」生成 `KDCG+日期+流水`，状态未推送；再「确认下推金蝶」。
6. 勾选 `KDCG2608160003` 任意一行应带出该单两行；可再勾 INV-B 后一起「确认下推金蝶」，按单号拆分。
7. 点「模拟应付单定时任务」：无发票的金蝶采购单跳过、应付保持未推送；`KDCG2608150001` 因两张发票不一致保持「推送异常」。应付未成功前可解绑/重配发票。

金蝶采购单号规则：`KDCG` + `YYMMDD` + 4 位当日流水，例如 `KDCG2608190001`。解绑不回收号段。

需求正文：`docs/PRD.md`。
